# Задание 1.5 — версии моделей

Один запрос к GPT-5.6 Luna, Terra и Sol: реальные ответы, время, токены и расчёт стоимости. Python, Flask, официальный OpenAI Responses API, HTML/CSS/JavaScript.

## Требования и подход

Условие: выполнить одинаковый запрос на слабой, средней и сильной моделях; сравнить качество, скорость и ресурсоёмкость. Результат — короткий вывод и ссылки; формат сдачи — видео и код. Ресурсоёмкость здесь означает расход токенов и стоимость запроса.

Допущение: три уровня одного семейства — Luna, Terra, Sol. Это роли в эксперименте, а не гарантия качества конкретного ответа. Точное условие получено от пользователя; недельная теория в доступных локальных материалах не найдена.

По умолчанию — три прогона каждой модели; можно выбрать один. Вызовы последовательные. Порядок: Luna–Terra–Sol, Terra–Sol–Luna, Sol–Luna–Terra. Общие инструкции, запрос, reasoning.effort=medium и лимит 6000 выходных токенов одинаковы. История, инструменты, temperature и top_p не передаются. Стандартная обработка; кеширование отключено через prompt_cache_options.mode=explicit без точек кеширования.

Время измеряется от вызова SDK до получения полного ответа, включая сеть. Ответы появляются целиком, по завершении каждого вызова; потока отдельных токенов нет. Прогоны доступны кнопками в каждой колонке. «Открыть последнее сравнение» загружает последний завершённый сохранённый запуск без новых API-вызовов.

## Запуск

Нужны Python 3.10+, интернет и ключ OpenAI с доступом ко всем трём моделям. Из корня проекта:

```text
cd week_1/task_5
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если .env отсутствует, скопируйте .env.example в .env и заполните OPENAI_API_KEY. Существующий .env не перезаписывайте.

```text
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:5005. Отправка выполняет 3 или 9 платных API-вызовов. Тайм-аут — 90 секунд на вызов, без автоматических повторов. Результаты сохраняются после каждого ответа в локальном docs/runs. При закрытии соединения уже отправленный API-вызов может завершиться и тарифицироваться.

## Метрики и тарифы

Вход, выход, общий расход и сведения о рассуждении/кеше берутся из usage API. Рассуждение уже входит в выходные токены и не суммируется повторно. Медианы рассчитаны только по завершённым непустым ответам. Общая стоимость учитывает все попытки с известным usage, включая незавершённые ответы; неизвестная стоимость не подменяется нулём.

Стандартные цены USD за миллион токенов, проверены 7 сентября 2026; короткий контекст:

Расчёт: (некешированный вход × цена входа + кешированный вход × цена кеша + выход × цена выхода) / 1 000 000. В эксперименте чтение и запись кеша равны нулю. Это расчёт по тарифам, без налогов и региональных надбавок; он не заменяет счёт провайдера. При несовместимых модели, режиме обработки или usage показывается неизвестная стоимость.

### Качество и короткий вывод

Критерии: оптимальность набора, верные суммы, соблюдение ограничений, корректность обоснования, русский язык и лимит 180 слов. Независимый перебор всех 256 подмножеств в тесте подтверждает единственный оптимум: A, D, E, H — 14 часов, ценность 30. Лучший набор с G — A, B, D, G, ценность 29; без G и H — A, B, C, D, F, ценность 28.

- Все три модели нашли оптимальный набор во всех трёх прогонах. По самому результату различий нет.
- Luna — самая дешёвая. В третьем прогоне ошиблась в доказательстве: максимум без H назван равным 28, хотя есть допустимый вариант ценностью 29. Первые два обоснования правильно учитывают этот случай.
- Terra — самая быстрая и с наименьшим расходом токенов. В первом прогоне та же ошибка про максимум 28 без H; также появилось грузинское слово вместо русского связующего слова. Во втором ответе не разобрана явно ветвь без G и H; в третьем она сведена к общему утверждению.
- Sol — самые последовательные обоснования в этом примере: явных арифметических или логических ошибок в трёх ответах не обнаружено. Стоит существенно дороже, а по медиане отвечает немного медленнее Luna.

Для этой задачи Luna выгоднее по цене, Terra — по скорости и токенам, Sol — по аккуратности объяснения. Меньшее число токенов не гарантирует меньшую стоимость: у Terra их меньше, чем у Luna, но тариф выше. Правильный итог не гарантирует правильного доказательства.

Один запрос и три повтора не дают универсального рейтинга моделей. Время зависит также от сети и нагрузки сервиса. Технически прерванный предварительный запуск не входит в сводку; его локальные записи сохранены.

## Ограничения

Приложение предназначено для локального запуска на 127.0.0.1. Одновременно выполняется одно сравнение на процесс. Тарифы зафиксированы на указанную дату и требуют обновления при изменении цен. Формат обычного текста запрашивается у API, но Markdown не удаляется принудительно. Загрузка последнего результата не запускает модели заново; это отмечено в интерфейсе.
