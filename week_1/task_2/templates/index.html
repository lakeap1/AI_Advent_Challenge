Управление ответом

Объект с полем answer — ровно 3 непустых пункта-строки. Формат задаётся инструкцией; структура проверяется.

Инструкция модели, не жёсткая обрезка. В JSON считаются только слова в трёх пунктах, без ключей. Превышение показывается под ответом.

stop=["[КОНЕЦ]"]

Модель пишет [КОНЕЦ], когда ответила на все части вопроса. API останавливает генерацию на маркере и не возвращает его.

В режиме JSON маркер запрашивается после закрывающей скобки. После него запрашивается контрольное продолжение — оно не должно прийти.

История видна только в этой вкладке. Каждый запуск независим: предыдущие ответы модели не отправляются.

Без ограничений

Один запрос. Разные настройки.Отправьте запрос, переключите параметры и отправьте его снова.

Готово к запросу

Одна отправка — один платный API-вызов. Текст ответа не обрезается приложением.
