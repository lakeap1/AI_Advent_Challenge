# Задание 1.1 — запрос к LLM через API

Локальное веб-приложение: введите вопрос в браузере, нажмите «Спросить Luna» и получите ответ модели `gpt-5.6-luna` через официальный OpenAI Responses API.

Приложение предназначено для локального запуска; хостинг не требуется.

## Требования

- Python с модулем `venv` и pip.
- API-ключ OpenAI с доступом к `gpt-5.6-luna` и доступ в интернет.
- Браузер.

Стек: Python, Flask, OpenAI SDK, HTML/CSS/JavaScript; тесты — pytest.

## Запуск

Откройте PowerShell в корне проекта и выполните:

```text
cd week_1/task_1
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если `.env` уже существует, пропустите копирование. Откройте его в редакторе и вставьте ключ в `OPENAI_API_KEY`. Не публикуйте этот файл.

Запустите сервер:

```text
.\.venv\Scripts\python.exe app.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). Не открывайте HTML-файл напрямую: запросы работают через Flask-сервер. Для остановки сервера нажмите Ctrl+C в терминале.

## Проверка

Из папки задания:

```text
.\.venv\Scripts\python.exe -m pytest -q
```

Автоматические тесты используют подставной API-клиент и не расходуют платные запросы.

## Файлы проекта

- [app.py](app.py) — сервер и обращение к модели.
- [templates/index.html](templates/index.html) — веб-интерфейс.
- [tests/](tests/) — тесты приложения.
- [.env.example](.env.example) — шаблон настройки ключа.

## Ограничения и ошибки

- Истории диалога и потокового ответа нет. Постепенное появление текста — анимация уже полученного ответа.
- Ответ показывается обычным текстом. Модель получает инструкцию не использовать Markdown, но это не принудительный фильтр ответа.
- При ошибке ключа проверьте `OPENAI_API_KEY`; при ошибке лимита — доступность API на стороне провайдера. После изменения настроек перезапустите сервер.
