# Задание 2.2 — агент с памятью

Локальный чат с gpt-5.6-luna, который сохраняет переписку в SQLite. Остановите приложение, запустите снова и продолжите разговор: агент загрузит сообщения и передаст их модели вместе с новым вопросом.

Условие Дня 7 — хранить messages в JSON или SQLite и восстанавливать контекст между запусками. Выбрана SQLite: сообщения и результаты запросов сохраняются транзакциями, без отдельного сервера базы данных. Это самостоятельное приложение на основе агента задания 2.1; запуск предыдущего задания не требуется.

Стек: Python 3.11+, Flask, httpx, SQLite из стандартной библиотеки, HTML/CSS/JavaScript. Один локальный пользователь, один чат и один процесс приложения на файл БД.

## Запуск

Нужны интернет и API-ключ OpenAI с доступом к gpt-5.6-luna. Вызовы оплачиваются по тарифу API.

В PowerShell из папки задания:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если .env уже есть, пропустите копирование. Укажите в нём OPENAI_API_KEY, затем запустите:

```powershell
.\.venv\Scripts\python.exe app.py
```

Откройте [http://127.0.0.1:5007](http://127.0.0.1:5007). Остановка — Ctrl+C в терминале. Debug и автоматическая перезагрузка выключены. После изменения кода, ключа или конфигурации перезапустите приложение.

## Использование и восстановление

Введите сообщение и нажмите «Отправить агенту». В ленте остаются сообщения и ответы, под каждым запросом — его токены, стоимость и результаты политик. Слева отображается общая стоимость чата.

Для самостоятельной проверки:

1. Сообщите агенту вымышленные сведения, например название проекта, время встречи и выбранный цвет. Дождитесь ответа.
2. Полностью остановите приложение и выполните команду запуска снова.
3. Нажмите «Обновить» в приложении или перезагрузите страницу. Переписка и расходы восстановятся.
4. Попросите напомнить сведения, не повторяя их в новом сообщении.

Обновление страницы само по себе не проверяет сохранение между процессами. Идентификатор запуска внизу страницы изменяется после нового запуска, а идентификатор чата остаётся прежним.

Если соединение оборвалось, сначала нажмите «Обновить»: ответ мог успеть сохраниться. Автоматического повторного обращения к модели нет.

## Где хранится контекст

По умолчанию файл — data/chat.sqlite3 относительно папки задания, независимо от текущего рабочего каталога. Он создаётся при первом запуске.

- messages: сообщения user и принятые ответы assistant с порядком и связью с запросом.
- requests: результат запроса, usage, USD, результаты политик и снимок тарифных метаданных.
- chat: постоянный идентификатор чата.

Допустимое сообщение пользователя и отметка начала запроса сохраняются до API. Ответ assistant и завершённый результат сохраняются одной транзакцией. После перезапуска незавершённый запрос получает статус interrupted; его расход остаётся неизвестным. Отклонённые ответы, ошибки и недопустимый ввод не добавляются в контекст как успешные ответы.

История берётся из базы на сервере. В следующий вызов Responses API передаются сообщения по порядку и текущие инструкции из конфига. Браузер не является хранилищем истории.

## Независимый агент

Flask отвечает за HTTP и интерфейс. Пакет agent владеет конфигом, политиками, историей, транспортом и расчётом расходов. Его можно использовать без веб-сервера:

```python
from dotenv import load_dotenv
from agent import create_agent

load_dotenv(".env")
agent = create_agent(db_path="data/my-chat.sqlite3")
try:
    result = agent.run("Помоги спланировать изучение новой темы.")
    print(result.status, result.text)
    print(agent.state()["summary"])
finally:
    agent.close()
```

create_agent принимает config_path, api_key и db_path. По умолчанию ключ читается из окружения, конфиг — из agent/config.toml. Для другого независимого чата передайте другой путь БД; запускайте не более одного экземпляра агента на один файл.

Agent.run(prompt) возвращает AgentResult с status/text/code, request_id, usage/cost_usd/usage_status, input_policy/output_policy. Agent.state() возвращает chat_id, messages, requests и summary. GET /api/state отдаёт это состояние с идентификатором запуска; POST /api/ask принимает JSON с полем prompt и возвращает результат вместе с актуальным состоянием.

## Конфиг и политики

В [agent/config.toml](agent/config.toml) находятся модель, инструкции, параметры, политики и тариф. Luna вызывается напрямую через HTTP Responses API, reasoning effort — none, service_tier — default, max_output_tokens — 1600. Неверный конфиг отклоняется при создании агента.

- Input policy nonempty_text: корректная строка Unicode, trim, непустой текст длиной до max_input_chars (4000 по умолчанию). Нарушение останавливает обработку до API.
- Output policy completed_text: завершённый ответ с корректной структурой, без refusal и с непустым текстом. Нарушение возвращает объяснение ошибки, не публикуя отклонённый текст как ответ.
- Название и результат каждой политики сохраняются в журнале запроса.
- judge отключён. Семантическая проверка истинности не реализована.
- Инструкция просит обычный текст без Markdown, кроме явно запрошенного другого формата. Это инструкция модели, а не принудительный фильтр.
- Интерфейс отображает текст безопасно и не исполняет HTML из ответа.

Сетевые ошибки, incomplete, refusal, отсутствие ключа и ошибки хранения сообщаются явно. Недоступная или повреждённая БД не заменяется молча пустой.

## Токены и стоимость

Usage берётся из ответа API: input_tokens, output_tokens, total_tokens, cached input и reasoning при наличии. Вход включает повторно переданную историю и инструкции. Cached — часть input, reasoning — часть output; они не прибавляются к total повторно.

Тариф хранится в конфиге с моделью, источником и датой проверки. Для стандартной [Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna) в пределах 272 000 входных токенов: $0.20 за миллион входных, $0.02 за кешированный вход, $1.20 за выход.

```text
USD = ((input - cached) × 0.20 + cached × 0.02 + output × 1.20) / 1 000 000
```

Стоимость сохраняется десятичной строкой. Для каждого запроса сохраняются запрошенные и фактические модель/режим обслуживания, снимок тарифа, его источник и дата. Изменение конфига не пересчитывает старые расходы.

- reported: API вернул корректные счётчики.
- unavailable: расход неизвестен.
- not_requested: вызова модели не было.
- Ответ, отклонённый output policy, всё равно учитывается в расходах, если usage получен.
- Если usage, кеш, тариф или соответствие модели/режима неизвестны, стоимость не подменяется нулём. Неподдерживаемая запись кеша и выход за область тарифа также дают неизвестную стоимость.
- При неопределённой стоимости хотя бы одного выполненного/прерванного запроса интерфейс показывает известную часть суммы и явно отмечает неполноту.

Summary содержит known_cost_usd, cost_complete, unknown_cost_requests и api_requests. Оценка в USD не заменяет счёт провайдера с его индивидуальными условиями и налогами.

## Проверка

Из папки задания:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты не обращаются к платному API. Они проверяют восстановление SQLite, точный payload истории, роли и порядок, политики, расходы при ошибках, прерванный вызов, ошибки хранения, последовательность запросов и маршруты Flask. Реальное продолжение разговора проверяется отдельно через приложение по сценарию выше.

## Ограничения и данные

- Один процесс и один экземпляр агента на БД. Параллельные запросы этого экземпляра выполняются последовательно.
- История не обрезается и не сжимается автоматически. По мере её роста увеличивается объём входных токенов; при превышении возможностей модели возможна ошибка API.
- Если процесс остановлен после API, но до записи результата, точная стоимость может остаться неизвестной. Повтор пользователь выполняет сам.
- SQLite хранит переписку открытым текстом на локальном диске. data/ и .env исключены из Git.
- Во время запроса история и инструкции уходят в облачный API OpenAI. Ключ остаётся на сервере и не записывается в историю. store=false отключает сохранение Response для последующего извлечения; это не утверждение об отсутствии всех журналов провайдера.
- Ответ модели может быть ошибочным: сохранение контекста не проверяет достоверность.
