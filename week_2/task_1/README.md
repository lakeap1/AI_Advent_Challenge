# Задание 2.1 — первый агент

Локальное веб-приложение: задайте вопрос и получите ответ gpt-5.6-luna через OpenAI Responses API. Агент — отдельный Python-пакет со своим конфигом, входной и выходной политиками; его можно использовать без Flask и браузера.

Условие дня 6: принять запрос пользователя, вызвать LLM через API и показать результат; логику запроса и ответа инкапсулировать в агенте. Выбран один независимый запрос без истории диалога. Стек: Python, Flask, HTTP-клиент httpx, HTML/CSS/JavaScript.

## Запуск

Требуются Python 3.11+, интернет, браузер и API-ключ OpenAI с доступом к указанной модели. Вызовы оплачиваются по тарифам вашего API-аккаунта.

В PowerShell из папки задания:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если .env уже существует, пропустите копирование. Укажите в нём OPENAI_API_KEY, затем запустите:

```powershell
.\.venv\Scripts\python.exe app.py
```

Откройте [http://127.0.0.1:5006](http://127.0.0.1:5006). Для остановки нажмите Ctrl+C в терминале. Сервер запускается локально без debug и автоматической перезагрузки. После изменения кода, ключа или конфига перезапустите его. Файлы и окружения заданий первой недели для запуска не нужны.

## Использование

Введите вопрос или выберите пример, нажмите «Отправить агенту». Во время запроса отображается ожидание. Затем появляется ответ либо объяснение ошибки. Каждый следующий запрос независим: предыдущие сообщения модели не передаются.

Пример:

```text
Объясни простыми словами, чем цель отличается от задачи. Приведи один короткий пример.
```

## Архитектура и контракт

```text
Браузер → Flask → Agent.run(prompt)
                   ├─ input policy
                   ├─ инструкции и параметры из конфига
                   ├─ HTTP → OpenAI Responses API
                   └─ output policy → AgentResult
```

Flask обрабатывает HTTP и отображение результата. Пакет agent владеет правилами, запросом к модели и обработкой ответа. HTTP-транспорт внутри пакета отвечает за доставку JSON, авторизацию и классификацию сетевых ошибок.

Агент возвращает неизменяемый AgentResult:

| Поле | Значение |
|---|---|
| status | ok, rejected или error |
| text | Ответ либо понятное объяснение отказа/ошибки |
| code | Пустая строка при успехе; машинный код при ошибке |
| usage | Входные, выходные, суммарные токены и детализация кеша/reasoning либо null |
| cost_usd | Оценка стоимости в USD десятичной строкой либо null |
| usage_status | reported — usage получен; unavailable — неизвестен; not_requested — LLM не вызывалась |

Использование из Python, запущенного в папке задания:

```python
from dotenv import load_dotenv
from agent import create_agent

load_dotenv('.env')
agent = create_agent()
result = agent.run('Что такое инкапсуляция? Ответь в двух предложениях.')
print(result.status, result.code)
print(result.text)
```

Для собственного конфига передайте create_agent(config_path='my-agent.toml'). Ключ читается из окружения либо передаётся аргументом api_key. Flask для этого не требуется.

## Конфиг и политики

[agent/config.toml](agent/config.toml) — конфиг агента: инструкции, модель, reasoning effort, лимит токенов, сетевой таймаут и выбор реализованных политик. Неизвестные поля, некорректные значения и неподдерживаемые политики вызывают ошибку конфигурации. Настройки фиксируются при создании экземпляра.

- Input policy nonempty_text: принимает корректную строку Unicode, удаляет крайние пробелы, отклоняет пустой ввод и текст длиннее max_input_chars (по умолчанию 4000). Отклонение происходит до API.
- Output policy completed_text: принимает завершённый ответ с корректной структурой, без отказа модели и с непустым текстом. Частичный ответ не выдаётся за успешный.
- max_output_tokens = 1600 ограничивает бюджет генерации, а не количество слов. Незавершённый ответ возвращает incomplete.
- timeout_seconds = 60 задаёт таймаут сетевых операций httpx; это не гарантия общего времени выполнения запроса.
- judge = disabled: дополнительная модель-оценщик не вызывается. Технические проверки выполняются кодом; оценка достоверности не реализована.

Политики реализованы в [agent/core.py](agent/core.py). Конфиг выбирает их по имени; произвольные правила на естественном языке не превращаются автоматически в проверки кода. Чтобы добавить новую программную политику, реализуйте её внутри пакета и зарегистрируйте в конфиге.

Инструкция модели просит обычный текст без Markdown; явно запрошенный пользователем формат имеет приоритет. Это инструкция, не принудительный фильтр. Символы, абзацы и формулы сохраняются, а браузер отображает результат как текст и не исполняет HTML.

## Токены и стоимость

Под ответом показаны input, output, общее число токенов и оценка стоимости запроса в USD. Значения берутся из usage ответа API. Input включает инструкции агента и пользовательский запрос. Cached input — часть input, reasoning — часть output; повторно к сумме они не прибавляются.

Тарифы хранятся в секции pricing собственного конфига агента. Для [Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna) стандартная обработка: $0.20 за миллион входных токенов, $0.02 за кешированный вход, $1.20 за выход. Дата проверки тарифа указана в конфиге. Запрос явно задаёт service_tier=default.

```text
Стоимость = ((input − cached) × 0.20 + cached × 0.02 + output × 1.20) / 1 000 000
Всего токенов = input + output
```

Расчёт сохраняется и при отклонении полученного ответа выходной политикой. Если API не вернул корректный usage, сведения о кеше неизвестны, обнаружена запись кеша, модель/режим не совпадают с тарифом или вход превышает область действия тарифа, стоимость отображается как неизвестная. Она не подменяется нулём. При отклонении ввода до LLM интерфейс явно показывает отсутствие расхода.

Это оценка по тарифу, без налогов и индивидуальных условий; она не заменяет счёт провайдера. Статистика прежних запросов не восстанавливается: приложение не хранит историю. Для другой модели нужно указать соответствующий тариф либо удалить секцию pricing и получать только токены.

## Ошибки и ограничения

- input_invalid, input_too_long: исправьте вход; API ещё не вызывался.
- not_configured, authentication: проверьте локальный ключ и доступ к модели.
- rate_limit, timeout, connection, provider_error: проверьте доступность API, баланс и параметры; повторную отправку выполняет пользователь.
- incomplete, refusal, empty_output, invalid_response: генерация не прошла выходную политику.

Автоматических повторов, дополнительного judge-вызова, инструментов, памяти и потокового вывода нет. Ответ появляется после завершения генерации. Модель может ошибаться: техническая проверка не доказывает истинность текста.

Приложение отправляет пользовательский запрос и инструкции в облачный API OpenAI. Ключ остаётся на сервере; в HTML и ответе приложения его нет. История локально не сохраняется. Для Responses API передаётся store=false; это не утверждение об отсутствии любых журналов у провайдера.

## Проверка

Из папки задания:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты не обращаются к платному API. Они проверяют агента без веб-сервера, влияние конфига, граничную длину входа, выходные политики, HTTP-запрос и ошибки транспорта, интеграцию Flask. Реальный вызов проверяется отдельно отправкой вопроса через запущенное приложение.
