# Оценка четырёх режимов основного чата

`questions.json` — фиксированный набор из десяти вопросов к README/коду с атомарными ожидаемыми фактами. Сравниваются `rag`, `rewrite`, `filter`, `rewrite_filter`. До вызовов фиксируются конфигурация, индекс и хеш эталонов. Для каждого вопроса четыре изолированные области получают одинаковый начальный снимок профиля, задачи и памяти; runtime — основной production Agent.run. Настройки или gold после просмотра результатов не меняются.

Экспорт версии 2 сохраняет каждый ответ, полные кандидаты, оценки/причины, выбранные источники, точный контекст, API-payloads и все оплаченные стадии. `no_context` — отказ хоста без generation API, а не успешный поиск ответа моделью. На вопросах с доступным ответом он снижает полноту; на вопросе без конкретного SHA проверяется честный отказ и отсутствие выдуманного значения.

Независимый проверяющий размечает каждый факт каждого режима: корректность, опору на реально переданные источники, их метки и причину. Дополнительно отмечает полный ответ, существенные неподтверждённые утверждения, отказ, достаточность кандидатов и контекста. Совпадение ожидаемого имени файла является ориентиром, а не доказательством. Нужно читать точный source slice и сопоставлять его с утверждением.

Машинный импорт связывает оценку с версией, ID прогона и хешем свидетельств; отклоняет неполные режимы/факты, неизвестные метки и противоречивую полноту. Он проверяет структуру разметки, а не заменяет содержательное ревью. До принятой оценки качество остаётся pending.

Сводка по режимам: корректные и поддержанные факты, полные ответы, достаточный контекст, неподтверждённые утверждения, `no_context/error/rejected`, API-вызовы, время и USD с признаком полноты суммы. Парные выигрыши и потери относятся к тем же вопросам. Результаты ограничены этим небольшим диагностическим набором и корпусом кода/README.
