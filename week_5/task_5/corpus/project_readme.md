# День 20. Оркестрация нескольких MCP-серверов

Локальный помощник по компьютерной графике и арту. Он объясняет техники и визуальные проблемы, работает с памятью и профилем, а для исследования темы может сам выбрать инструменты нескольких MCP-серверов, подготовить отчёт, сохранить его и проверить чтением.

## Возможность дня 20

Три самостоятельных stdio-процесса предоставляют отдельные каталоги инструментов:

| Сервер | Инструменты | Назначение |
| --- | --- | --- |
| research | lookup_wikipedia, search_stackexchange | Получить теоретические материалы и практические случаи |
| processing | compare_sources, prepare_report | Сопоставить найденные материалы и подготовить разбор |
| library | save_report, read_report | Сохранить принятый отчёт и проверить его содержимое |

Приложение обнаруживает инструменты через MCP tools/list и квалифицирует их как server__tool. Вложенный цикл Responses API выбирает каждый следующий инструмент и получает фактический результат предыдущего. Порядок первых двух исследований может различаться. Код проверяет зависимости, принадлежность идентификаторов запуску и схемы аргументов/результатов до дальнейших действий.

Обычный вопрос отправляется в тот же чат. Для исследования нескольких источников внешний агент выбирает orchestrate_graphics; внутри него модель выбирает отдельные MCP-вызовы. Это отдельная возможность от сохранённой композиции дня 19 research_and_save для одного источника. Простые вопросы могут обходиться без инструментов.

В интерфейсе видны обнаруженные серверы, последовательность вызовов, аргументы, результаты и состояния. Полный результат инструмента раскрывается отдельным элементом. После успеха доступны точный сохранённый текст, SHA-256 и скачивание TXT. Обновление страницы восстанавливает журнал того же запуска и не повторяет запрос к модели.

## Требования и запуск

Python 3.11 или новее, доступ в интернет, OpenAI API-ключ с доступом к gpt-6-luna. Стек: Python, Flask, Responses API, MCP SDK 2.2.0, SQLite, Pydantic и JSON Schema. Самостоятельная папка содержит исходники предыдущих возможностей и не требует импортов из других заданий.

В PowerShell, из папки задания:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Запишите OPENAI_API_KEY в локальный .env. Ключ не отправляется в браузер и не должен попадать в Git. Затем:

```powershell
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:5020. Новые MCP-процессы запускаются приложением автоматически для каждого исследования. Отдельный хостинг для этой возможности не нужен. Активная модель, ограничения, input/output policies, инструкции и тариф находятся в agent/config.toml.

## Пример использования

```text
Разбери normal mapping: возьми теорию из Wikipedia и практический пример из Blender Stack Exchange, сравни материалы и составь короткий разбор причин швов normal map и проверок. Сохрани его и проверь чтением из библиотеки.
```

Ожидаемый флоу включает шесть отдельных MCP-вызовов на трёх серверах: два исследования, сравнение, подготовку отчёта, сохранение и чтение. Успех подтверждается только после сравнения прочитанных байтов с ожидаемым текстом и SHA-256. Источники добавляются из фактически полученных материалов.

Ранее сохранённый отчёт доступен в контексте следующих сообщений. Это справочная память: она не заменяет инструкции, правила задачи или новый запрос пользователя.

## Политики и расходы

Агент сохраняет результаты собственных input/output policy вместе с метаданными запросов. Отклонённый вход останавливается до LLM; отклонённый результат останавливает дальнейший флоу и не передаётся сохранению. Текущие инварианты задачи проверяются перед записью отчёта. Ошибка инструмента, неверные аргументы, неизвестное имя, чужой идентификатор, раннее сохранение или неверное чтение останавливают взаимодействие без скрытого повтора.

Панель «Расходы» показывает фактические input_tokens, output_tokens и total_tokens, cached input и reasoning при наличии, USD каждого вызова и накопленную сумму чата. Выбор инструментов, финальный ответ, память и проверки учитываются отдельными записями. MCP-вызов сам по себе не является вызовом LLM. Reasoning входит в output и повторно не оплачивается. Отказ после оплаченного вызова сохраняет полученный usage; неизвестные usage/расходы не превращаются в ноль, общая сумма отмечается неполной.

По умолчанию gpt-6-luna работает со стандартной обработкой и reasoning=none. Сохранённый тариф за миллион токенов: input $0.10, cached input $0.01, cache writes $0.125, output $0.50; источник — официальная страница модели, проверено 30.09.2026. Оценка расходов не заменяет счёт провайдера; при несовпадении модели/режима или выходе за поддержанный диапазон стоимость может быть неизвестной.

Пользовательский ответ запрашивается обычным текстом без Markdown; параметры инструментов сохраняют JSON. Программные проверки не доказывают истинность рекомендаций и не являются оценкой качества визуального ассета. Модель не осматривает файл, которого пользователь не предоставлял.

## Локальные данные и ограничения

SQLite хранит диалоги, память, расходы и журнал оркестрации. Отчёты сохраняются в подкаталоге orchestration каталога данных; имя генерирует приложение. Произвольный путь и перезапись существующего файла не принимаются. Переменная CHAT_DATA_DIR меняет корень данных. Данные, .env и результаты исключены из Git.

Профиль, диалог и ветка фиксируются при запуске; чужой результат недоступен через маршруты текущего рабочего пространства. Это локальная изоляция, а не сетевой механизм авторизации. Запускайте один экземпляр приложения на каталог данных и используйте loopback. После рестарта незавершённый запуск отмечается прерванным без автоматического повтора.

Вложенный цикл ограничен 12 шагами модели и 10 вызовами инструментов. Один пользовательский запрос запускает не более одного исследования. Используются ограниченные текстовые фрагменты публичных Wikipedia/Stack Exchange API; изображения, весь сайт и полный корпус обсуждений не анализируются. Пустая выдача или недоступный источник могут остановить исследование. Выдача и доступность внешних API меняются.

Успешная запись и финальный ответ чата — разные результаты: если отчёт сохранён и проверен, а последующий ответ отклонён, отчёт остаётся фактическим результатом инструментов; ответ не объявляется принятым, все выполненные вызовы учитываются.

## Сохранённые возможности

Память, персонализация, управляемые этапы задачи, инварианты, ветвление диалогов, поиск, сводки о графике и композиция одного источника сохранены. Для обычного поиска сервер knowledge_server использует KNOWLEDGE_MCP_URL, по умолчанию http://127.0.0.1:8017/mcp:

```powershell
.\.venv\Scripts\python.exe -m knowledge_server.server
```

Сводки используют DIGEST_MCP_URL, по умолчанию http://127.0.0.1:8018/mcp:

```powershell
.\.venv\Scripts\python.exe -m digest_server.server
```

При недоступном сервере сводок доступна локальная история с предупреждением. Оркестрация трёх stdio-серверов и композиция одного источника не требуют запущенных HTTP-серверов знаний или сводок.

## Проверки и состав исходников

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pytest -q tests -k orchestration
```

Регрессионные проверки охватывают старые функции и новые границы маршрутизации/зависимостей/учёта. Детерминированные тесты не требуют OpenAI-ключа. Проверки настоящего stdio-транспорта используют MCP SDK; фиктивный выбор модели в тесте не является живым API-вызовом. Для проверки внешних источников и модели используйте обычный запрос в приложении.

Пять дополнительных браузерных регрессий отключены по умолчанию. Для проверки панелей, мобильной навигации, профиля, памяти, источников, расходов и веток установите Playwright и Chromium:

```powershell
.\.venv\Scripts\python.exe -m pip install playwright==1.63.0
.\.venv\Scripts\python.exe -m playwright install chromium
$env:RUN_UI_TESTS = "1"
.\.venv\Scripts\python.exe -m pytest -q tests/test_chat_ui.py
```

Эти тесты запускают отдельные локальные Flask-приложения с временными данными и тестовым транспортом модели; они не вызывают платный API.

- app.py, orchestration_routes.py — Flask и маршруты журнала/скачивания.
- orchestration/ — регистрации, MCP-серверы, сервисы, хранилище, маршрутизатор и модельный цикл.
- agent/ — агент, конфигурация, policies, токены, память и существующие действия.
- composition/, knowledge_server/, digest_server/ — сохранённые MCP-возможности.
- templates/, static/ — интерфейс чата и трасса оркестрации.
- tests/ — регрессионные и транспортные проверки.
