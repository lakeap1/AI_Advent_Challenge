# Unity 6.0: отключение sRGB sampling

Авторский краткий пересказ официальной документации Unity Technologies, проверено 2026-10-11. Версия: Unity 6.0 (6000.0). Источник: https://docs.unity3d.com/6000.0/Documentation/Manual/disable-srgb-sampling-textures.html .

## Сохранение исходного пространства текстуры

Чтобы импортировать текстуру в исходном цветовом пространстве изображения без sRGB sampling, откройте её Inspector, выберите Texture Type по назначению текстуры и снимите sRGB (Color Texture), если этот флажок отображается.

Это настройка конкретного texture asset. Она не заменяет выбор Color Space всего проекта.

Пример применения в проекте: если текстура хранит числовые параметры материала, а преобразование sRGB этих значений не требуется, используйте подходящий Texture Type и отключите показанный флажок. Это поясняющий пример назначения настройки, а не результат измерения конкретной сцены.
