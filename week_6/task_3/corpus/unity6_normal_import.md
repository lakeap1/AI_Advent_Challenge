# Unity 6.0: импорт normal map

Авторский краткий пересказ официальной документации Unity Technologies, проверено 2026-10-11. Версия: Unity 6.0 (6000.0). Источник: https://docs.unity3d.com/6000.0/Documentation/Manual/texture-type-normal-map.html .

## Тип текстуры и направление Y

Texture Type = Normal map подготавливает импортированную текстуру для normal mapping в реальном времени.

Flip Green Channel инвертирует зелёный канал, представляющий направление Y. Это полезно, когда карта использует другую конвенцию, чем ожидает Unity. При впечатлении, что выпуклости стали впадинами, проверьте тип Normal map и соглашение зелёного канала; инверсия нужна при несовпадении конвенций.

## Создание из высоты и доступ из кода

Create From Grayscale создаёт normal map из серой heightmap; Bumpiness управляет силой наклона полученных нормалей. Это отдельный случай от импорта готовой карты.

Read/Write сохраняет дополнительную копию данных текстуры для обращения из скрипта и удваивает требуемую память текстуры. Он выключен по умолчанию; включайте его при необходимости доступа из кода.
