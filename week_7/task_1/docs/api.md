# HTTP API сервиса «Грани»

API обслуживает только сайт текущего пользователя. Регистрация, управление моделью, выполнение инструментов и чтение произвольных файлов через HTTP отсутствуют. Администратор создаёт учётную запись через `python -m graphics.cli create-user USERNAME`; пароль вводится в терминале без передачи как аргумент.

## Личные учебные материалы итоговой сборки

`POST /api/branches/<branch_id>/materials` принимает только `{ "message_id": "..." }`. Сервер проверяет владельца ветки и принятый assistant-turn, сохраняет вопрос, точный ответ и источники в личный файл. Клиент не задаёт путь, владельца или произвольный текст. Сохранение не вызывает LLM и возвращает путь, SHA-256, размер и `download_url`. Повтор не перезаписывает изменённый файл и сообщает конфликт. Ограничения личной области: 24 документа, 16 384 байта UTF-8 на документ; обрезки нет.

`GET /api/materials/download?path=outputs/answer-....md` отдаёт владельцу точные байты личного файла как `text/plain` attachment с `private, no-store`. Применяются ограничения путей Workspace. Анонимный или другой пользователь не получает файл. API и данные многофайловых предложений сохраняют отдельное подтверждение перед записью.

## Сессия и защита запросов

При запуске требуется `GRAPHICS_SECRET_KEY` длиной не менее 12 символов. Пустой ключ закрывает запуск. В production нужны HTTPS и `GRAPHICS_SECURE_COOKIES=1` (значение по умолчанию). Cookie сессии подписана Flask и имеет `Secure`, `HttpOnly`, `SameSite=Strict`. В ней хранится случайный идентификатор; его хэш и срок 12 часов находятся в серверной SQLite-базе, а выход аннулирует запись. Если reverse proxy меняет схему запроса, задайте точный `GRAPHICS_PUBLIC_ORIGIN=https://домен` в окружении процесса; иначе сервер сопоставляет `Origin` со схемой и `Host` запроса, доверяя `X-Forwarded-Proto` только от loopback proxy. Все POST, PATCH, PUT и DELETE требуют заголовки `Origin` и `X-CSRF-Token`. Токен возвращает `GET /api/csrf`, после входа он меняется и приходит в ответе входа или `GET /api/bootstrap`. JSON обязателен для изменяющих API-запросов.

Вход ограничен десятью попытками с одного IP за 15 минут. Счётчики находятся в `GRAPHICS_DATA_DIR/auth_limits.sqlite3` и переживают перезапуск процесса. Вопросы и явное сжатие истории вместе ограничены двадцатью действиями в минуту для пользователя и шестьюдесятью для IP. Тело запроса ограничено 48 КиБ, длина вопроса — 8000 символов. Обычно IP берётся из соединения. Если приложение получает запрос от loopback reverse proxy, проверенный `X-Real-IP` задаёт клиентский адрес для лимита; proxy должен перезаписывать этот заголовок, а не пересылать значение клиента. Основная защита вопросов по пользователю работает независимо от этого.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/healthz` | Публичное минимальное `{"ok":true}`. |
| GET | `/` | Страница входа и приложения. |
| GET | `/api/csrf` | Начальный CSRF-токен для входа. |
| POST | `/api/login` | `{"username":"…","password":"…"}`; создаёт закрытую сессию и возвращает новый токен. |
| POST | `/api/logout` | Завершает сессию, тело `{}`. |
| GET | `/api/bootstrap` | Профиль, память, список чатов и текущий CSRF-токен. |
| GET, POST | `/api/chats` | Список чатов; создание с необязательным `title`. |
| GET | `/api/chats/<chat_id>/branches` | Ветки своего чата, чтобы открыть их после обновления страницы. |
| GET, PATCH | `/api/branches/<branch_id>` | Состояние своей ветки; PATCH принимает `title` и/или полный объект `conditions`. |
| POST | `/api/branches/<branch_id>/fork` | Новая ветка от `message_id` своей ветки. |
| POST | `/api/branches/<branch_id>/ask` | Вопрос `{"question":"…","request_id":"необязательный стабильный ID"}`; возвращает статус, только принятый ответ и его использованные источники. |
| POST | `/api/branches/<branch_id>/compress` | Явно обновляет сводку старой истории, тело `{}`. |
| PATCH | `/api/profile` | Частичные поля `role`, `level`, `goal`, `depth`; роль и уровень независимы. |
| POST | `/api/memories` | Сохраняет или исправляет запись `{"key":"…","value":"…"}`. |
| DELETE | `/api/memories/<memory_id>` | Забывает собственную запись. |
| GET | `/api/ledger?chat_id=<id>` | Учёт токенов и оценка стоимости своего чата; без параметра — всего пользователя. |
| GET | `/reference/<id>` | Текст разрешённого локального источника после входа. |

`/reference/<id>` принимает ровно `readme`, `usage`, `architecture`, `api`, `glossary`, `support-faq`. Эти значения закреплены за README, тремя публичными файлами `docs/`, глоссарием и каноническим FAQ поддержки. Путь из запроса никогда не превращается в путь файловой системы. Внешние источники из ответа открываются по их HTTPS/HTTP ссылке.

`request_id` нужен для безопасного повтора той же команды поддержки в той же ветке. Повтор с изменённым вопросом отвергается; незавершённый первый запрос возвращает `pending`, а не запускает действие второй раз. Команды `/support` без второго вопроса возвращают `support_control` и безопасное уведомление без вызова модели. Подтверждённые изменения содержат `support_confirmation` с разрешёнными полями квитанции; неизвестный исход не выдаётся за успешное изменение.

Ветка и сообщения выдаются без внутренних снимков состояния и черновиков. Если ответ отклонён, клиент получает статус и безопасное сообщение, а уже выполненные вызовы учитываются в журнале. `GET /api/ledger` возвращает общие известные `input_tokens`, `output_tokens`, `total_tokens`, `known_cost_estimated_usd`, `complete`, `cost_estimated_usd` и список `calls`. В каждой записи доступны только `stage`, `model`, `status`, `usage` (input/output/total/cached_input/reasoning при наличии), `cost_estimated_usd`, безопасные `tariff_source` и `tariff_checked_on`. Хэши запросов, исходные метаданные, политики и трассы остаются на сервере. Отсутствующие или чужие ID отвечают `404`; нет входа — `401`; нет корректного Origin/CSRF — `403`; неверное тело — `400`/`413`/`415`; лимит — `429`. Тексты ошибок не содержат исходный запрос или черновик. `cost_estimated_usd=null` означает неизвестную полную стоимость, а не ноль; оценка по обычному API-тарифу не доказывает фактическое списание bundle.
