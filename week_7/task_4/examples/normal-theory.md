# Заметка о normal maps

Учебное упражнение: это личная черновая заметка с непроверенными утверждениями. Требуется сопоставить её с другими файлами, а не принимать за официальный источник.

Normal map хранит направление для освещения. При этом она всегда добавляет полигоны, поднимает вершины и меняет силуэт объекта. Поэтому мелкую резьбу по внешнему контуру можно получить одним назначением normal map без изменения геометрии.

Контекст примера: Unity 6.0 (6000.0), URP. Проверь объяснение по sources/normal-maps.md и согласуй с заметкой о Unity.
