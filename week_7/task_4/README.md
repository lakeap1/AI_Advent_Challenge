# Грани: работа с учебными файлами

Это расширение закрытого образовательного сайта по компьютерной графике. Обычный чат продолжает объяснять теорию и примеры Unity; панель «Материалы» помогает сопоставить несколько личных учебных файлов, подготовить проверяемое предложение и сохранить его после вашего подтверждения. Для работы требуется исходный сервис из `../task_1` в том же дереве `week_7`. Исходники `task_2` и `task_3` этому расширению не требуются.

Личная область создаётся для учётной записи на сервере. `sources/name.md` служит источником только для чтения; предложения могут создать или изменить `notes/name.md` и `outputs/name.md`. Владелец определяется по сеансу входа, а не по параметру запроса. Частные файлы не добавляются автоматически в общий индекс RAG. Учебные примеры добавляются отдельной кнопкой, не перезаписывают существующие файлы и содержат намеренное противоречие в заметках о normal map.

## Два учебных сценария

Войдите в сайт, откройте чат и панель «Материалы», нажмите «Добавить учебные примеры». Для первого сценария в поле «Учебная цель» введите:

```text
Подготовь краткую памятку для начинающего: чем отличаются материал, шейдер и текстура в Unity, как они связаны и от каких версии Unity и render pipeline зависят примеры. Используй мои учебные источники и предложи отдельный файл с памяткой.
```

После подготовки проверьте список прочитанных источников, объяснение, полный новый текст и diff. Кнопка «Сохранить эти изменения» применяет именно показанное предложение. Затем откройте файл в списке: текст перечитывается с сервера.

Для второго сценария оставьте созданные примеры и задайте новую цель:

```text
Сопоставь мои заметки о normal map с учебными источниками, найди намеренное противоречие и предложи согласованные правки обеих связанных заметок. Объясни, что normal map меняет в освещении и чего не меняет в геометрии.
```

Снова изучите источники и diff до подтверждения. Если после подготовки кто-то изменил прочитанный файл или цель записи, сохранение сообщит о конфликте и не начнёт запись; подготовьте новое предложение. При частичной ошибке записи смотрите фактически сохранённые пути и их содержимое. Повтор применения уже сохранённого предложения не должен восстанавливать изменённый позже файл. Если панель сообщает, что подтверждение предложения ещё не завершено, используйте «Проверить состояние»; до принятого состояния предложение нельзя применить.

## Окружение и запуск

Нужны Python 3.12+, Git checkout проекта, зависимости из `requirements.txt`, доступный локально `qwen3-embedding:0.6b` через Ollama и серверный ключ Z.ai для `glm-5.3-flash`. Сначала подготовьте корпус и индекс базового сервиса по [его инструкции](../task_1/README.md); архив этого задания не содержит `task_1`, корпус или постоянные данные.

Из каталога `week_7/task_4` в Linux можно подготовить окружение так:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
export PYTHONPATH="$(cd ../task_1 && pwd)"
export GRAPHICS_DATA_DIR="$(pwd)/data"
export GRAPHICS_REPO_ROOT="$(git rev-parse --show-toplevel)"
```

Перед запуском загрузите `ZAI_API_KEY`, случайный `GRAPHICS_SECRET_KEY` длиной не менее 12 символов, `GRAPHICS_PUBLIC_ORIGIN` с точным внешним HTTPS origin и, если адрес отличается от стандартного, `GRAPHICS_EMBEDDING_URL` из защищённого окружения процесса. Секреты не помещайте в Git, аргументы команды или браузер. Постоянный `GRAPHICS_DATA_DIR` должен сохраняться при обновлениях. За HTTPS reverse proxy запустите приложение через `server:app`:

```sh
gunicorn --bind 127.0.0.1:5031 --workers 1 --threads 4 --timeout 300 server:app
```

Открытой регистрации нет. Администратор создаёт учётную запись интерактивно в базовом сервисе с тем же `GRAPHICS_DATA_DIR`:

```sh
(cd ../task_1 && python -m graphics.cli create-user owner)
```

Пароль запрашивается без вывода. Панель «Материалы» появляется после входа в обычный сайт. Подготовка предложения вызывает модель и учитывает те же ограничения, что чат; простое открытие файлов модель не вызывает.

## Ограничения, приватность и расходы

Личная область ограничена 24 документами по 16 384 байта UTF-8. Цель содержит не более 4 000 символов; при подготовке выбираются 2–4 файла и предлагаются 1–3 изменения. Процесс может выполнить до четырёх вызовов модели, включая отдельную смысловую проверку. Источники `sources/` доступны только для чтения. Предложение проходит программные проверки и смысловую проверку до показа; отклонённый черновик нельзя применить. Смысловая проверка снижает риск ошибки, но не гарантирует истинность объяснения.

Общий учёт чата сохраняет фактические токены и оценку USD по тарифу для всех выполненных вызовов, включая отклонённые ответы. Если usage или стоимость неизвестны, это остаётся неизвестным и дальнейшие платные стадии блокируются. Оценка API-тарифа не доказывает фактическое списание предоплаченного bundle. Личные файлы остаются вне общего RAG и не входят в архив исходников; доступ к ним требует действующей учётной записи. Для публичного доступа нужен настроенный HTTPS и защищённый серверный каталог данных.

## Проверки и архив исходников

Запускайте модульные и интеграционные проверки из этого каталога в отдельном окружении без производственных секретов и `GRAPHICS_PUBLIC_ORIGIN`:

```sh
python -B -m unittest discover -s tests -p 'test_*.py' -v
(cd ../task_1 && python -B -m unittest discover -s tests -p 'test_*.py' -v)
```

Эти тесты используют подставные ответы провайдера; доступность живого API, качество ответа и внешнего сайта проверяются отдельно. Для передачи только исходников этого задания создайте новый архив в исключённом каталоге `demo/`:

```sh
python -B scripts/package_deployment.py . demo/task4-source.tar.gz
```

Упаковщик возвращает число файлов и SHA-256 архива. Внутри находятся только явно разрешённые README, зависимости, точка входа, исходники, примеры и тесты `task_4`; ссылки, `data/`, `demo/`, `docs/`, `notes/`, отдельные файлы ключей и окружение исключены. Перед передачей архив всё равно нужно просмотреть: секрет, ошибочно записанный прямо в исходник, нельзя надёжно обнаружить по имени файла. Архив не заменяет соседний `task_1` и сам по себе не запускает сервис.
